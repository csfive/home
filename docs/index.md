# 关于

## 短文

以前每讲都写完整笔记，概念、例子和踩坑都会写进去。一篇会写很长，写完就没有再看过。

这些内容现在 AI 都能讲，而且比我讲得全。

所以这里只留短文：每个主题写一段，讲清机制和常见的坑，不追求覆盖所有细节。扫一遍，知道的跳过，想深入再让 AI 展开。
