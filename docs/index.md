# 关于

## 提纲与展开

以前每讲都写完整笔记，概念、例子和踩坑都会写进去。一篇会写很长，写完就没有再看过。

这些内容现在 AI 都能讲，而且比我讲得全。

所以每讲先列提纲，一行一个主题，扫一遍，知道的跳过。想深入再看对应的展开短文，那里补了机制、例子和讲义之外的延伸。
