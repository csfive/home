# 课程覆盖与反馈

这站是二次笔记，不是课程录像的文字版。每讲都标出来源和核对程度，没核对的部分直接写在这里。

## 来源

| 课程             | 讲义             | 视频             | 练习     |
| ---------------- | ---------------- | ---------------- | -------- |
| Missing Semester | 2026 官方讲义    | YouTube 录像     | 课后练习 |
| CS50G            | 官方 notes、源码 | CS50 播放器、SRT | Project  |

## 核对状态

| 讲次        | 视频字幕核对 | 结果                                                                               |
| ----------- | ------------ | ---------------------------------------------------------------------------------- |
| MS 00–02    | 已核对       | 补了路径导航、Tab 补全、`SIGCONT`、`PS1` 转义、LSP 与 AI 补全的边界等              |
| MS 07–08    | 已核对       | 补了维护权限、`git bisect run`、属性测试、`pytest-vcr`、Vim 正则差异等             |
| MS 03–06    | 未核对       | YouTube 字幕接口持续返回 429，暂时只按讲义与练习整理                               |
| CS50G 00–07 | 已核对       | 官方 SRT 逐周对照，补了 `love.timer.getFPS`、`table.slice`、碰撞回调和状态机细节等 |

## 能保证什么

- 讲义里的主题、命令、代码示例和常见的坑，在对应页面里都有落点。
- 视频里明确讲到、讲义里没有的主题，已经按字幕补进提纲与正文。
- 每讲的提纲小节都链接到展开页；结构由 `bun run check:notes` 检查。

## 不能保证什么

- 自动字幕会漏字、断句、拼错 API 名；核对按主题覆盖，不按逐字转写。
- 课堂演示、现场问答、玩笑和课程管理不收录。
- 正文里标为「延伸」的内容是讲义之外的补充，不是课程原文。
- 视频之外的口头补充如果字幕没识别出来，仍可能缺失。

## 怎么反馈

每页底部有「提交反馈」，会打开一个预填页面地址的 GitHub issue。也可以直接发给我：

```text
页面：/ms/04/merge
小节：解决顺序
原句：冲突期间索引里同时保存 base、ours、theirs 三份版本
问题：这句话看不懂 / 和 `git checkout --ours` 的行为对不上
```

带上页面路径、小节标题和原句，比「这页看不懂」更容易定位。想直接改也可以点每页底部的「直接改这页」。
