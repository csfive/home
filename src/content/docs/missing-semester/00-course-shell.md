## 终端是什么

上世纪六七十年代，主机在机房，通过一根串口线连到你桌上的终端。

Terminal 这个词的原意就是“线路的末端”。

典型的是 VT100 屏幕终端，更早的是电传打字机（Teletype，缩写为 TTY，这个缩写后来也成为了终端的代名词）。

它不计算任何东西，只做两件事：

- 输入：把按键变成字节，从串口线发出去
- 输出：把发回来的字节打到屏幕或纸上

真正的计算全在机房的主机上。

硬件终端早就不生产了，现代的“终端”其实是**终端模拟器**（Terminal Emulator），一个普通的 GUI 程序，假装自己是 VT100。

它做的事情还是那两件，只不过换成了窗口：

- 输入：键盘、鼠标、粘贴
- 输出：把字节渲染成字符、颜色、光标

还多了更多东西：标签页、分屏、透明度等等。

叫“模拟器”是因为 VT100 那套控制码（`\e[2J` 清屏，`\e[31m` 变红）成了标准，今天的终端都在照做。它模拟的是**协议**，而不是硬件。
